# Приглашение на свидание

Одностраничная открытка в стиле пиксельной аркады. Экран «старт» → вопрос «Пойдёшь со мной
на свидание?» → кнопка «Нет» убегает от курсора и от пальца, а за ней бегает пиксельный кот →
«Да» открывает маршрут дня из двух пунктов.

**Живая версия:** https://lxrdkisake.github.io/dlya-tebya/

## Как поменять текст

Открой `src/page.html`, найди блок `const CONFIG = {` в начале `<script>`:

```js
const CONFIG = {
  name:      "Алиса",                 // её имя
  nameGen:   "",                      // родительный падеж («только для Алисы»)
                                      // пусто — просклоняется само
  signature: "Андрей",                // подпись
  date:      "суббота, 22 августа",

  place1:    "Грузинский ресторан",   // пункт 1
  time1:     "14:00",
  note1:     "Хачапури, вино и долгий разговор ни о чём...",

  place2:    "Кошачья деревня",       // пункт 2
  time2:     "сразу после",
  note2:     "Десятки котов, и все они будут твои...",

  askLead:   "Программа уже готова, и в ней есть коты...",

  icsStart:  "2026-08-22T14:00",      // для кнопки «В календарь»
  icsEnd:    "2026-08-22T18:00"       // (пусто — кнопка спрячется)
};
```

Пустые поля просто не выводятся — вёрстка не ломается.

Потом:

```bash
python build.py                       # склеивает src/page.html + шрифты -> index.html
python src/og.py                      # перерисовывает превью для мессенджера (если менял имя)
git add -A && git commit -m "текст" && git push
```

Сайт обновится примерно через минуту.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | **собранная страница**, один файл на 238 КБ со вшитыми шрифтами |
| `src/page.html` | исходник; вместо шрифтов маркер `/*__FONTS__*/` |
| `build.py` | вклеивает шрифты и проверяет, что внешних запросов не осталось |
| `assets/fonts/fonts.css` | Unbounded + Press Start 2P + Onest в base64 (кириллица + латиница) |
| `assets/cats/*.gif` | коты: 4 стикера, 2 пиксельных и спрайт-лист `oneko.gif` |
| `og.png` | превью для ссылки в мессенджере |
| `src/og.py` | скрипт, который рисует `og.png` |
| `src/ttf/` | те же шрифты в TTF — нужны только для `og.py` |
| `CREDITS.md` | откуда взяты картинки и под какой лицензией |

## Как устроена убегающая кнопка

Во всех похожих проектах, что попались в сети, «Нет» прыгает в случайную точку без всяких
проверок — и регулярно улетает за экран или садится прямо на «Да». Здесь иначе:

- **Выбор точки.** До 60 кандидатов, из них берётся самый дальний от курсора; кандидаты,
  пересекающиеся с «Да» (плюс отступ 26 px), отбрасываются; координаты зажаты в границы
  `visualViewport`, ниже бегущей строки и кнопки звука.
- **Мышь.** Убегает не по наведению, а по приближению — как только курсор ближе
  ~46 px до края кнопки.
- **Телефон.** Уходит по `pointerdown` с `preventDefault()`, то есть тап физически
  не успевает превратиться в клик.
- **Клавиатура.** На Enter/Space тоже убегает, но фокус не крадёт.
- **Кот.** Спрайт из `oneko.js` получает новую цель при каждом побеге и бежит туда.
  Догнав, садится и через какое-то время засыпает.
- После 10 побегов кнопка исчезает совсем, надписи по пути: `Нет → Точно нет? → А как же
  коты? → Там сотня котов → Всё, я сдаюсь…`

«Да» тем временем растёт с каждым побегом и меняет надпись на «Да!» и «Конечно да».

## Прочее

- Внешних запросов нет вообще — `build.py` падает, если найдёт хоть одну ссылку на другой хост.
- Звук — Web Audio, квадратная волна, без единого аудиофайла. Есть кнопка отключения.
- Частицы и конфетти — `<canvas>`, сердечки нарисованы по клеточкам под пиксельный стиль.
- `prefers-reduced-motion` уважается: кот не появляется, частицы замирают, бегущая строка стоит.
- Проверено на 390×844 и 360×640: горизонтального скролла нет, тач-цели от 44 px.
