# Приглашение на свидание

Одностраничная открытка-приглашение. Конверт → вопрос «Пойдёшь со мной на свидание?»
→ кнопка «Нет» убегает от курсора и пальца → «Да» открывает экран с деталями свидания.

**Живая версия:** https://lxrdkisake.github.io/dlya-tebya/

## Как поменять текст

1. Открой `src/page.html`, найди блок `const CONFIG = {` (в самом начале `<script>`).
2. Впиши свои значения:

```js
const CONFIG = {
  name:      "Аня",                    // её имя (пусто — будет «Привет, красивая»)
  place:     "Ресторан «Веранда»",     // название ресторана
  date:      "суббота, 22 августа",
  time:      "19:00",
  address:   "ул. Ленина, 12",
  pickup:    "заеду за тобой в 18:30", // можно оставить пустым
  signature: "Андрей",                 // подпись

  icsStart:  "2026-08-22T19:00",       // для кнопки «Добавить в календарь»
  icsEnd:    "2026-08-22T22:00"        // (пусто — кнопка спрячется)
};
```

Пустые поля просто не показываются — страница остаётся целой.

3. Пересобери и запушь:

```bash
python build.py
git add -A && git commit -m "текст" && git push
```

Через ~1 минуту обновится сайт.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | **собранная страница** — один самодостаточный файл (231 КБ), работает даже офлайн |
| `src/page.html` | исходник; вместо шрифтов стоит маркер `/*__FONTS__*/` |
| `build.py` | вклеивает шрифты в исходник → `index.html` |
| `assets/fonts/fonts.css` | шрифты Marck Script, Cormorant, Nunito (кириллица + латиница) в base64 |
| `og.png` | картинка-превью для ссылки в мессенджере |
| `src/og.py` | скрипт, который рисует `og.png` |

## Что внутри

- Никаких внешних запросов — шрифты, иконки и анимации вшиты в файл (build.py это проверяет).
- Убегающая «Нет»: уворачивается от мыши по расстоянию, а на телефоне уходит по `pointerdown`,
  так что тап по ней не срабатывает. Не вылезает за экран и не наезжает на «Да».
  После 10 побегов — исчезает.
- «Да» растёт с каждым побегом, надпись меняется: Да → Да! → Конечно да!
- Сердечки и лепестки на `<canvas>`, конфетти на «Да», звуки на Web Audio (без файлов).
- Уважает `prefers-reduced-motion`, работает с клавиатуры, контраст текста ≥ 4.5:1.
